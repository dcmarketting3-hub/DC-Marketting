# DC Marketting Website

Static GitHub Pages website for **DC Marketting**.

## Folder structure

```text
DC-Marketting/
├── index.html
├── style.css
├── script.js
├── README.md
├── robots.txt
├── sitemap.xml
└── assets/
    ├── logo.png
    ├── logo-full.png
    ├── social-campaigns.png
    ├── lead-campaigns.png
    └── brand-assets.png
```

## Upload instructions

1. Open the GitHub repository: `DC-Marketting`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, `robots.txt`, and `sitemap.xml` in the root folder.
3. Create or upload the `assets` folder with all five image files inside it.
4. Commit changes.
5. Go to **Settings > Pages**.
6. Select **Deploy from branch**, choose `main`, and select `/(root)`.
7. Wait 2–5 minutes.
8. Open the website and press **Ctrl + F5** to hard refresh.

## Website URL

https://dcmarketting3-hub.github.io/DC-Marketting/

## Important

Do not rename the image files unless you also update the same names in `style.css` and `index.html`.
