# DC Marketting Website

A premium static website for DC Marketting, ready to host on GitHub Pages.

## Files
- `index.html` — website structure and content
- `style.css` — complete responsive styling
- `script.js` — mobile menu, animations and WhatsApp enquiry form
- `assets/logo.svg` — clean logo inspired by the business card
- `assets/favicon.svg` — browser tab icon

## How to upload on GitHub
1. Create a new GitHub repository.
2. Upload all files and folders exactly as given.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch: `main` and folder: `/root`.
6. Click **Save**.

Your website will be live at the GitHub Pages URL after deployment.
